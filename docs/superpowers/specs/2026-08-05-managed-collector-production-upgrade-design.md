# 托管采集器与生产升级设计

## 目标

以已在 6173 验证的 `1.0.0-rc.2`/协议 v2 为基线，形成可部署的托管采集器版本，随后把 5173 业务服务和三台业务机采集器升级到同一版本。普通用户不再接触 token、启动命令、PowerShell、BAT 或自启目录。

## 不变量

- 5173 的 `cargo-platform-data` 原卷必须保留，并在部署前生成可校验 SQLite 快照。
- 一次打印就是一个来源事件；内容相同也不得按内容去重。
- 服务器、网络或采集器中断后，只能在服务端确认入库后推进水位。
- 修复安装、升级和凭证更换不得重置本地水位、来源 epoch 或待补传状态。
- 不停止、不修改三台业务机上的打印软件和其他业务进程。
- 旧版采集器只在新版心跳、打印组件和本地状态均验证后退出运行路径；旧文件先归档，保留回退副本。

## 当前问题

1. 管理页面仍要求生成 token、下载 ZIP、复制命令并人工启动。
2. 离线超过 24 小时后，查看采集连接会禁用并软删除采集器、清空 token，导致本可恢复的掉线变成人工重装。
3. 现有临时部署脚本只复制 EXE 并启动一次，没有开机启动、崩溃拉起、凭证保护、修复安装和升级回退。
4. 6173 已具备协议 v2、任务窗口补传、来源 epoch、服务端确认后推进水位、单实例锁和发布清单；这些能力应直接复用，不重写采集协议。

## 选定方案

### 服务器兼容升级

先把 5173 后端、解析器和前端升级到新版本。新后端继续接受三台旧采集器的既有 token 和旧心跳，因此服务器升级与采集器升级可以解耦、逐台完成。

离线超时只影响展示状态，不得自动撤销设备。只有管理员明确点击“移除”才撤销凭证。

### 连接码与一次性登记

管理页面生成一个 `CP1.` 开头的连接码。连接码只封装系统公开地址和一次性登记 token，用户只需要复制一个字段。

新接口使用一次性登记 token 换取长期设备 token；交换成功后立即旋转 token，使连接码不能再次使用。已部署业务机升级时允许从旧配置迁移既有 token，不要求重新登记。

### Windows 托管安装

下载物仍是一个 PyInstaller EXE。默认双击进入安装界面；自动化部署使用同一 EXE 的静默安装参数，不增加 MSI、第三方服务包装器或常驻 PowerShell。

- 程序：`%ProgramFiles%\CargoPlatformCollector\collector.exe`
- 状态、配置、日志和回退文件：`%ProgramData%\CargoPlatformCollector`
- 凭证：Windows DPAPI 机器范围加密
- 托管：Windows 任务计划程序，SYSTEM 开机启动、失败一分钟后重启、禁止并行实例、隐藏运行

安装时原子迁移 `%LOCALAPPDATA%\CargoPlatformCollector` 中的旧配置和状态。新版安装失败时恢复旧 EXE 和旧计划任务，不删除旧状态。

### 修复与升级

重复运行新版安装器即执行保留状态的修复/升级：结束的只允许是已确认的旧采集器进程；先备份旧 EXE 和任务 XML，再替换、注册任务、启动并等待心跳。失败则恢复旧 EXE、任务和配置。

本版不建设独立自动更新服务。发布清单和 SHA-256 继续作为安装包完整性守门；后续机器规模增长后再复用同一安装入口做管理员批准的静默更新。

### 旧版本清理

每台机器验证新版后：

1. 导出所有包含采集器命令的计划任务和自启项。
2. 把旧 EXE、配置副本、任务 XML 和自启脚本移动到带时间戳的回退目录。
3. 删除旧运行入口，不删除已迁移的新状态和日志。
4. 确认只有一个新版采集器进程和一个托管任务。

## 故障处理

| 故障 | 行为 |
|---|---|
| 网络或服务端中断 | 保持进程，持续重连，水位不前移 |
| 采集器崩溃 | 任务计划程序自动拉起 |
| 电脑重启 | SYSTEM 开机任务自动启动 |
| 打印数据库暂不可读 | 保持运行并上报稳定错误分类 |
| 凭证失效 | 明确显示需修复，不按机器名偷偷重绑 |
| 状态损坏 | 使用可验证备份；无法恢复时停止推进并报警，不清空水位猜测 |
| 升级失败 | 恢复旧 EXE、任务和状态 |

## 部署顺序

1. 在隔离分支实现并跑完整回归。
2. 部署到 6173 数据副本并执行断网、杀进程、重启任务、重复事件和升级回退验证。
3. 对 5173 创建数据库快照、镜像回退清单和容器状态清单。
4. 升级 5173 四个业务容器并验证原数据、页面和旧采集器仍在线。
5. 按右边、中间、左边逐台备份、升级和验证采集器；任一台失败只回退该台。
6. 三台均稳定后清理旧入口，完成一次真实采集闭环检查。

## 验收

- 新装只需下载、双击、粘贴一个连接码；无 CMD、PowerShell 和明文 token。
- 杀进程、重启任务、断网、服务端重启及离线超过 48 小时均能恢复。
- 离线期间的每个来源打印事件均补传；相同内容的两次打印保留两次。
- 旧采集器与新后端过渡兼容，三台可以逐台升级。
- 5173 数据库哈希、完整性检查和业务行覆盖在升级前后均有记录。
- 每台业务机有精确的回退目录和恢复命令。
